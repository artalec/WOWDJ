# DJPlayer для macOS

Профессиональный DJ-плеер для macOS с поддержкой crossfade и high-cut filter эффектов.

## Возможности

✅ **Управление плейлистами**
- Создание, переименование и удаление плейлистов
- Изменение порядка плейлистов
- Настройка цвета для каждого плейлиста
- Автоматическое сохранение при закрытии приложения

✅ **Управление треками**
- Добавление аудио файлов (MP3, WAV, M4A и др.)
- Двойной клик для воспроизведения
- Изменение порядка треков в плейлисте
- Удаление треков

✅ **Горячие клавиши**
- `Пробел` - воспроизведение/пауза
- `Esc` - остановка трека

✅ **Визуализация**
- Waveform в реальном времени для играющего трека
- Отображение текущего времени и длительности
- Цветовая индикация плейлистов

✅ **DJ эффекты**
- **Crossfade** - плавный переход между треками (настраиваемая длительность 1-10 сек)
- **High-Cut Filter** - эффект "уводения" звука как на DJ контроллерах (настраиваемая длительность 0.5-5 сек)
- Следующий трек запускается только после полного завершения эффекта

## Системные требования

- macOS 13.0 (Ventura) или новее
- Xcode 15.0 или новее (для компиляции)

## Инструкция по компиляции через GitHub

### 1. Создайте репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и войдите в свой аккаунт
2. Нажмите на кнопку "New repository" (зеленая кнопка)
3. Введите название репозитория, например: `DJPlayer`
4. Выберите "Public" или "Private"
5. Нажмите "Create repository"

### 2. Загрузите файлы в репозиторий

**Вариант A: Через веб-интерфейс GitHub**

1. На странице вашего пустого репозитория нажмите "uploading an existing file"
2. Перетащите все файлы и папки проекта в окно браузера
3. Введите commit message: "Initial commit"
4. Нажмите "Commit changes"

**Вариант B: Через командную строку (если установлен Git)**

```bash
# Перейдите в папку с проектом
cd /path/to/DJPlayer

# Инициализируйте git репозиторий
git init

# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Initial commit"

# Добавьте удаленный репозиторий (замените YOUR_USERNAME и YOUR_REPO)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Отправьте код на GitHub
git branch -M main
git push -u origin main
```

### 3. Автоматическая компиляция

GitHub Actions автоматически запустит сборку после загрузки кода:

1. Перейдите на вкладку **Actions** в вашем репозитории
2. Дождитесь завершения процесса сборки (обычно 5-10 минут)
3. Зеленая галочка ✅ означает успешную сборку

### 4. Скачайте готовое приложение

1. На вкладке **Actions** откройте завершенную сборку
2. Прокрутите вниз до раздела **Artifacts**
3. Скачайте `DJPlayer-macOS.zip`
4. Разархивируйте и перетащите `DJPlayer.app` в папку **Applications**

### 5. Первый запуск

При первом запуске macOS может показать предупреждение:

1. Откройте **Системные настройки** → **Конфиденциальность и безопасность**
2. Найдите предупреждение о DJPlayer и нажмите **Открыть в любом случае**
3. Подтвердите открытие приложения

## Использование

### Создание плейлиста

1. Нажмите кнопку `+` в левой панели
2. Введите название плейлиста
3. Плейлист появится в списке

### Добавление треков

1. Выберите плейлист в левой панели
2. Нажмите кнопку **"Добавить треки"** со значком `+`
3. Выберите аудио файлы (можно выбрать несколько)
4. Треки появятся в списке

### Воспроизведение

1. Выберите трек в списке
2. Нажмите `Пробел` или дважды кликните по треку
3. Waveform появится в верхней части окна
4. Для остановки нажмите `Esc`

### Настройка эффектов

**Crossfade** (в правом верхнем углу):
1. Включите переключатель "Crossfade"
2. Настройте время перехода (1-10 секунд)
3. При запуске нового трека произойдет плавный переход

**High-Cut Filter** (рядом с Crossfade):
1. Включите переключатель "High-Cut Filter"
2. Настройте длительность эффекта (0.5-5 секунд)
3. При запуске нового трека текущий трек постепенно "уйдет" с эффектом фильтра
4. Новый трек запустится только после завершения эффекта

### Управление плейлистами

- **Переименование**: Наведите на плейлист → три точки → "Переименовать"
- **Изменение цвета**: Три точки → "Изменить цвет"
- **Удаление**: Три точки → "Удалить"
- **Изменение порядка**: Перетащите плейлист вверх/вниз

## Сохранение данных

Все плейлисты, треки и настройки автоматически сохраняются в:
```
~/Library/Application Support/DJPlayer/appstate.json
```

При следующем запуске все данные восстанавливаются автоматически.

## Устранение проблем

### Приложение не запускается

- Убедитесь, что у вас macOS 13.0 или новее
- Проверьте настройки безопасности (см. раздел "Первый запуск")

### Не воспроизводятся треки

- Проверьте, что аудио файлы не повреждены
- Убедитесь, что формат поддерживается (MP3, WAV, M4A, FLAC, AAC)
- Проверьте системные настройки звука

### GitHub Actions не запускается

- Убедитесь, что файл `.github/workflows/build.yml` находится в правильной папке
- Проверьте вкладку Actions - она должна быть включена в настройках репозитория
